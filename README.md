Resume Job Matcher

An AI-powered web application that analyzes a resume and compares the user's skills with a given job description.

🚀 Features

- 📄 Upload Resume
- 📝 Enter Job Description
- 🎯 Match Resume Skills with Job Requirements
- 🏷️ Display Skill Badges
- 📊 Show Match Score
- 📈 Display Progress Bars
- 💡 Provide Skill Suggestions
- 🔍 Show Research/Job Information
- 📱 Responsive User Interface

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- React
- FastAPI
- AWS

📌 Skill Status

The application displays skills based on their availability:

- ✓ Available
- ⚠ Needs Improvement
- ✕ Missing

Example:

- Python ✓

🎯 Project Goal

The goal of this project is to help job seekers understand how well their resume matches a particular job description and identify skills that may need improvement.
